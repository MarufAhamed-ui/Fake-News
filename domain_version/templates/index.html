PROJECT SCOPE

A transparent baseline

This prototype uses text cleanup, word TF-IDF, Logistic Regression, and local feature contributions. It does not use images, social-network signals, early propagation data, a transformer, or external evidence retrieval.

The score describes learned patterns in this dataset. It cannot establish whether a new claim is true or false. The ISOT real and fake files also come from different publisher groups, so dataset performance may reflect source and writing-style cues.
